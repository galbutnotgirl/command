Install Guide

First-time beta install, macOS permissions, setup checks, and source install.

Download Current Release

Command requires macOS 14 or later.

  1. Open the latest GitHub Release.
  2. Download newest Command-*.zip asset attached to that release.
  3. Unzip it.
  4. Move Command.app to ~/Applications.
  5. Control-click Command.app in Finder, choose Open, then choose Open again.

If macOS only shows Move to Trash, open System Settings -> Privacy & Security, scroll down, click Open Anyway, authenticate, then reopen Command.

xattr -dr com.apple.quarantine ~/Applications/Command.app

Published builds identify their signing status in release notes. Never bypass a verification warning for an app from an untrusted source.

Binary installs do not require Terminal scripts. Global shortcuts, screenshots, clipboard history, and dictation run from the app.

Existing Installs

Command was previously named ClaudeCommand. New installers use Command.app and remove the old ~/Applications/ClaudeCommand.app bundle during source installs. The bundle identifier and local support paths stay compatible (com.claudecommand and ~/Library/Application Support/claude-command/) so macOS permissions, shortcuts, history, and exports keep working across the rename.

For permission details, optional items, and reset commands, see Permissions.

First Run

Open the menu-bar icon, then choose Settings -> Set Up.

After granting permissions, restart Command if a required Set Up item still shows red.

Verify Install

In Settings -> Set Up, confirm Accessibility, screenshot permission if needed, Microphone/model status if needed, and Clipboard History if enabled.

TestExpected
Select text and press F8Selected text sends to existing Claude chat.
Press Command-F8New Claude chat opens with captured text.
Press F6Clipboard History picker opens.

If F-keys control brightness, media, or dictation instead of Command, enable standard function keys in macOS Keyboard settings, rebind prompt shortcuts in Settings -> Shortcuts, or rebind dictation shortcuts in Settings -> Dictation Settings.

Install From Source

Source install is mainly for local development or testing unreleased changes.

It requires macOS 14 or later plus Xcode command-line tools.

git clone https://github.com/galbutnotgirl/command
cd command
time ./qualify-installed-build.sh

Qualification runs the full regression suite, signs a commit-bound test attestation into the app, installs incrementally, and validates running shortcuts, microphone, restart, and final-word behavior. Direct builds cannot replace the installed app without an explicit test-only override.

For isolated unqualified UI development, use:

./script/build_and_run.sh --allow-unqualified

That explicit development path stops the running app and launches the local bundle. It must not replace the daily installed app. Use ./script/build_and_run.sh --allow-unqualified --verify to confirm isolated runtime readiness; verify mode pings the app dispatch socket and checks bundled docs.

Optional, if you want the legacy SendHelper keystroke fallback for source testing:

./build-helper.sh

Optional, if you want legacy right-click Services in macOS Services menus:

./install-quick-action.sh
./set-hotkeys.sh

For downloaded app installs, use Settings -> About -> Copy Diagnostic Info and review it before sharing. From a repo checkout, maintainers can also run:

./doctor.sh
